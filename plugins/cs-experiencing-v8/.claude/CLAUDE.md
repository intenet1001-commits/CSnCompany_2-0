# cs-experiencing - 경험 지식 저장소

이 플러그인은 누적된 학습 경험을 도메인별로 관리합니다.

**버전은 디렉토리명이 단일 진실** — `ls -d "$BASE/<도메인>-v"* | sort -V | tail -1`로 항상 최신을 해석한다.
문서에 버전 숫자를 하드코딩하지 않는다.

도메인 목록(개수·순서: `test → plan → review → design → clarify → smart-run → ceo`)·사용법·디렉토리 구조의
단일 진실은 `skills/experiencing/SKILL.md` — 여기에 복제하지 않는다.
에이전트 구성·개수의 단일 진실은 각 도메인(예: `$LATEST_TEST/commands/CS-test.md`)의 로스터다.
