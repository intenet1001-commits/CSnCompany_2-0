CS Memory 2.1

기억은 모으고,
에이전트는 필요한 만큼만 성장시킵니다.

사용자가 기억할 것은 네 가지입니다. AgentsToZ 기억 변화만 수집하고, 컴팩트하게 학습하고, 관련 에이전트만 업그레이드하고, 현재 상태를 확인합니다.

1

변화 학습

원본 기억은 수정하지 않고 안정적인 엔트리 버전 변화만 학습합니다.

2

정기 수집

6시간마다 파일 스탬프를 확인하고 바뀐 기억만 무토큰으로 수집합니다.

3

에이전트 업그레이드

검증된 후보를 담당 CS 도메인에만 반영하고 실제 변경된 버전만 올립니다.

4

상태 확인

마지막 학습, 미처리 후보, 관련 에이전트 버전을 한 번에 확인합니다.

평소에는 이 네 명령만

버튼을 누르면 명령어가 그대로 복사됩니다. 자연어 문장으로 말해도 같은 스킬이 작동합니다.

세션 판단의 저장 소유자는 AgentsToZ

`/cs-end`는 검증된 세션 결론을 프로젝트 로컬 remember-session 어댑터에 위임하며 별도 전역 기억을 만들지 않습니다. 처음 발견한 기존 기억은 baseline으로만 기록하고, 명시적 learn도 과거 후보 최대 20개·본문 한 번에 최대 5개로 제한하며 초과 요청은 거부합니다. 중복 memoryId와 credential 의심 본문은 fail closed 상태로 모델에 전달하지 않습니다. shared digest도 safe pending 20개, scan 256 files/4 MiB, header 200개, 최종 JSON 128 KiB로 제한하고 legacy secret row를 격리합니다. state 파일은 POSIX의 검증된 parent directory FD/no-follow 상대 연산과 Windows의 reparse-point no-follow/delete-share 제외 ancestor handle로 경로 재바인딩을 방어합니다. CS CEO는 종료 단계에서 actionable pending이 있을 때만 같은 세션으로 learn pending을 한 번 처리합니다.

명령어를 기억하기 싫다면 아래 문장을 그대로 붙여 넣으세요.

/cs-memory:learn here
현재 프로젝트만 장기기억 학습해줘

학습 후 개선할 것이 있는지 확인

미처리 장기기억 후보가 있으면 관련 에이전트만 업그레이드해줘

특정 폴더 또는 PC 범위 정기 수집

/cs-memory:schedule install folder /absolute/projects
/cs-memory:schedule install pc

세션에서만 알 수 있는 내용 저장

/cs-end

프로젝트 기억이 설정된 경우 AgentsToZ 장기기억 에이전트에 한 번만 위임합니다.

아무것도 바꾸지 않고 확인

장기기억 학습 상태와 미처리 에이전트 업그레이드 후보를 보여줘

무엇이 달라졌나요?

사용자에게 남긴 것

  • learn: 변경된 현재 기억 버전을 컴팩트 후보로 변환
  • schedule: 모델 없이 정기 변화 포인터 수집
  • upgrade: 근거 기반 선택적 에이전트 개선
  • status: 통합 읽기 전용 상태
  • cs-end: 검증된 세션 결론을 AgentsToZ 기억 소유자에게 위임

공개 메뉴에서 제거한 것

  • long-term-memory-training train-local 같은 긴 명령
  • cs-experiencing test/plan/review/design 중복 래퍼
  • update와 version-up all 무조건 전체 버전업
  • checkpoint, pipeline 등 다른 도메인의 역할

Claude Code 설치·전환

기존 `cs-core-memory`가 설치되어 있다면 제거한 뒤 새 이름으로 설치합니다.

/plugin uninstall cs-core-memory@CSnCompany_2-0 /plugin install cs-memory@CSnCompany_2-0 /reload-plugins

기존 플러그인이 설치되지 않았다면 첫 줄은 생략하세요. Codex에만 Git 변경이 있고 Claude Code에는 아직 반영되지 않았다면, csn-sync로 Codex의 변경을 Claude Code 쪽에 동기화한 뒤 설치합니다.
