CS Memory 2.0

기억은 모으고,
에이전트는 필요한 만큼만 성장시킵니다.

사용자가 기억할 것은 세 가지입니다. 프로젝트 변경을 장기기억에 학습하고, 누적된 교훈으로 관련 에이전트만 업그레이드하고, 현재 상태를 확인합니다.

1

장기기억 학습

이전 커서 이후 변경된 프로젝트만 찾아 기억과 후보 큐를 갱신합니다.

2

에이전트 업그레이드

검증된 후보를 담당 CS 도메인에만 반영하고 실제 변경된 버전만 올립니다.

3

상태 확인

마지막 학습, 미처리 후보, 관련 에이전트 버전을 한 번에 확인합니다.

평소에는 이 세 명령만

버튼을 누르면 명령어가 그대로 복사됩니다. 자연어 문장으로 말해도 같은 스킬이 작동합니다.

자주 사용

모든 프로젝트 학습

등록된 프로젝트 중 변경된 곳만 증분 학습합니다.

/cs-memory:learn
장기기억 학습
주기적으로

에이전트 업그레이드

누적 후보를 검토해 관련 에이전트만 개선합니다.

/cs-memory:upgrade
에이전트 업그레이드
필요할 때

통합 상태 확인

학습 커서, 후보 수, 도메인 버전을 읽기 전용으로 확인합니다.

/cs-memory:status
장기기억 상태

상황별 복사용 문장

명령어를 기억하기 싫다면 아래 문장을 그대로 붙여 넣으세요.

현재 프로젝트만 학습

/cs-memory:learn here

학습 후 개선할 것이 있는지 확인

세션에서만 알 수 있는 내용 저장

/cs-end

장기기억 학습을 정상 실행했다면 매번 호출할 필요는 없습니다.

아무것도 바꾸지 않고 확인

장기기억 학습 상태와 미처리 에이전트 업그레이드 후보를 보여줘

무엇이 달라졌나요?

사용자에게 남긴 것

  • learn: 변경된 프로젝트 기억과 후보 큐
  • upgrade: 근거 기반 선택적 에이전트 개선
  • status: 통합 읽기 전용 상태
  • cs-end: 자동 수집이 불가능한 세션 경험 보충

공개 메뉴에서 제거한 것

  • long-term-memory-training train-local 같은 긴 명령
  • cs-experiencing test/plan/review/design 중복 래퍼
  • update와 version-up all 무조건 전체 버전업
  • checkpoint, pipeline 등 다른 도메인의 역할

Claude Code 설치·전환

기존 `cs-core-memory`가 설치되어 있다면 제거한 뒤 새 이름으로 설치합니다.

/plugin uninstall cs-core-memory@CSnCompany_2-0 /plugin install cs-memory@CSnCompany_2-0 /reload-plugins

기존 플러그인이 설치되지 않았다면 첫 줄은 생략하세요. Codex에만 Git 변경이 있고 Claude Code에는 아직 반영되지 않았다면, csn-sync로 Codex의 변경을 Claude Code 쪽에 동기화한 뒤 설치합니다.
